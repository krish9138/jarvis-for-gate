## 1. Network Scaling by Geographical Scope
1. **PAN (Personal Area Network)**: Within a few meters (Bluetooth mouse/keyboard, Zigbee smart bulbs).
2. **LAN (Local Area Network)**: Rooms, office buildings, university campuses (High speed 100 Mbps–10 Gbps, low latency, private ownership).
3. **MAN (Metropolitan Area Network)**: Spans a city or municipal area (34–150+ Mbps; e.g., Cable TV networks, city-wide WiMAX, municipal fiber).
4. **WAN (Wide Area Network)**: Spans countries, continents, or global links (Leased lines, MPLS, Satellite links, Internet).
5. **VPN (Virtual Private Network)**: Creates secure encrypted "tunnels" over public networks (the Internet) using IPsec protocols, allowing remote clients to appear on the internal private LAN.

## 2. Four Generations of Ethernet Evolution (IEEE 802.3)
| Generation | Standard | Data Rate | Physical Medium & Specs | Key Notes |
|---|---|---|---|---|
| **1st Gen: Standard Ethernet** | IEEE 802.3 | **10 Mbps** | • **10Base5**: Thick coaxial cable (500m max)<br>• **10Base2**: Thin flexible coax (185m max)<br>• **10Base-T**: UTP copper cable (100m max) | CSMA/CD access method. 10Base-T transitioned to star topology with central hub/switch. |
| **2nd Gen: Fast Ethernet** | IEEE 802.3u | **100 Mbps** | • **100Base-TX**: 2 pairs of Cat 5 UTP (100m)<br>• **100Base-FX**: 2 strands of optical fiber (2000m)<br>• **100Base-T4**: 4 pairs of Cat 3 UTP (100m) | Preserved original 10 Mbps frame format and MAC addressing for full backward compatibility. |
| **3rd Gen: Gigabit Ethernet** | IEEE 802.3z / 802.3ab | **1 Gbps** (1000 Mbps) | • **1000Base-T**: 4 pairs of Cat 5e/6 UTP (100m)<br>• **1000Base-SX**: Short-wavelength laser, multi-mode fiber (550m)<br>• **1000Base-LX**: Long-wavelength laser, single-mode fiber (5 km) | Backbone for enterprise campus networks and data centers. |
| **4th Gen: 10-Gigabit Ethernet** | IEEE 802.3ae | **10 Gbps** (10,000 Mbps) | • **10GBase-SR**: Multi-mode fiber (300m)<br>• **10GBase-LR**: Single-mode fiber (10 km)<br>• **10GBase-ER**: Single-mode fiber (40 km)<br>• **10GBase-T**: Cat 6a/7 UTP (100m) | Shifted Ethernet from LAN to MAN/WAN interconnects; full-duplex only (no CSMA/CD). |

## 3. OSI 7-Layer Architecture vs TCP/IP Protocol Suite
```
OSI 7-LAYER MODEL                                TCP/IP PROTOCOL SUITE
┌──────────────────────────┐                      ┌──────────────────────────┐
│ Layer 7: Application     │ ──┐                  │                          │
├──────────────────────────┤   │                  │ Layer 4: Application     │
│ Layer 6: Presentation    │ ──┼────────────────> │ (HTTP, FTP, SMTP, DNS,   │
├──────────────────────────┤   │                  │  DHCP, Telnet)           │
│ Layer 5: Session         │ ──┘                  │                          │
├──────────────────────────┤                      ├──────────────────────────┤
│ Layer 4: Transport       │ ───────────────────> │ Layer 3: Transport       │
│                          │                      │ (TCP, UDP)               │
├──────────────────────────┤                      ├──────────────────────────┤
│ Layer 3: Network         │ ───────────────────> │ Layer 2: Internet        │
│                          │                      │ (IP, ICMP, ARP, IGMP)    │
├──────────────────────────┤                      ├──────────────────────────┤
│ Layer 2: Data Link       │ ──┐                  │ Layer 1: Network         │
├──────────────────────────┤   ├────────────────> │ Interface / Host-to-Net  │
│ Layer 1: Physical        │ ──┘                  │ (Ethernet, Wi-Fi, PPP)   │
└──────────────────────────┘                      └──────────────────────────┘
```

### Detailed OSI Layer Functions:
1. **Layer 1: Physical Layer**:
   - Transmits raw, unstructured bit streams over physical media.
   - Specifies mechanical/electrical connectors, pin assignments, signal voltages, data rates, simplex/half-duplex/full-duplex modes.
2. **Layer 2: Data Link Layer**:
   - Organizes bits into **Frames** with headers and trailers (FCS / CRC).
   - Handles **Hop-to-Hop physical addressing (MAC addresses)**, flow control, error detection, and media access control (CSMA/CD on shared channels).
3. **Layer 3: Network Layer**:
   - Handles **End-to-End logical addressing (IP addresses)** and packet routing across intermediate heterogeneous networks.
4. **Layer 4: Transport Layer**:
   - Handles **Process-to-Process (Port-to-Port)** message delivery.
   - Performs **Segmentation and Reassembly**, end-to-end error control, and flow control.
   - Protocols:
     - **TCP (Transmission Control Protocol)**: Connection-oriented, reliable, guaranteed error-free in-order delivery, flow control, retransmission.
     - **UDP (User Datagram Protocol)**: Connectionless, lightweight, low overhead, no flow control or retransmission; ideal for real-time audio/video streaming, DNS, DHCP.
5. **Layer 5: Session Layer**:
   - Establishes, manages, synchronizes, and terminates dialogues/sessions between applications; inserts checkpoints in file transfers.
6. **Layer 6: Presentation Layer**:
   - Handles **Syntax and Semantics** of data: Data translation (ASCII to EBCDIC), **Data Compression**, and **Data Encryption / Decryption**.
7. **Layer 7: Application Layer**:
   - Provides network services directly to user applications and end-user interfaces (HTTP, FTP, SMTP, DNS, DHCP).

## 4. Lectures 10 & 11 - Practice Questions & Answer Key
1. **Q1 (L11)**: Real-time video streaming protocol minimizing latency $\rightarrow$ **(b) UDP** (connectionless, low overhead).
2. **Q2 (L11)**: Protocol automatically assigning IP address without manual configuration $\rightarrow$ **(d) DHCP**.
3. **Q3 (L11)**: OSI layer for data translation, compression, and encryption $\rightarrow$ **(b) Presentation Layer**.
4. **Q4 (L11)**: Breaking large message into smaller units at Transport Layer $\rightarrow$ **(c) Segmentation** (Data Link is Framing; Network is Packetizing).
5. **Q5 (L11)**: TCP/IP layer equivalent to OSI Network Layer $\rightarrow$ **(c) Internet Layer**.
6. **Q6 (L11)**: Functions of OSI lower layers (Physical, Data Link, Network) $\rightarrow$ **(b) 1, 2 and 3 only** (Session management is Layer 5).
7. **Q7 (L11)**: TCP vs UDP accurate statements $\rightarrow$ **(a) 1 and 2 only** (TCP connection-oriented, UDP connectionless and faster).
8. **Q8 (L11)**: TCP/IP Application layer functions $\rightarrow$ **(c) 1, 2 and 3 only** (Reliable end-to-end delivery is Transport layer).
9. **Q9 (L11)**: Key responsibilities of Data Link Layer $\rightarrow$ **(b) 2 and 3 only** (Organizing frames, controlling media access).
10. **Q10 (L11)**: Why TCP/IP is practical $\rightarrow$ **(a) 1 and 3 only** (ARPA project origin, flexible/scalable on billions of devices).
11. **Hospital backbone over 3 km with EMI interference**: $\rightarrow$ **(d) 1000Base-LX** (Single-mode fiber up to 5 km, immune to EMI).
12. **Office wing desktop connections within 90 meters at 1 Gbps on copper**: $\rightarrow$ **(c) 1000Base-T**.
